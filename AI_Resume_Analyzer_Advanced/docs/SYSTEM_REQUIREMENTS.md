# System Requirements

## Functional
1. Registration/login
2. Profile management
3. PDF/DOCX resume upload
4. Resume parsing
5. NLP preprocessing
6. Skill extraction
7. Job description management
8. Job description analysis
9. Resume-job matching
10. Match score
11. Skill gap analysis
12. Resume quality score
13. Job recommendations
14. Skill recommendations
15. Candidate dashboard
16. Admin panel
17. REST API
18. Match history

## Non-Functional
- Security
- Performance
- Accuracy
- Reliability
- Usability
- Scalability
- Maintainability
- Responsive design
- Browser compatibility

## Hardware
Minimum: Intel i5/Ryzen 5, 8 GB RAM, 256 GB SSD.
Recommended: Intel i7/Ryzen 7, 16 GB RAM, 512 GB SSD.

## Software
Frontend: HTML, CSS, JavaScript
Backend: Python Flask
Database: MySQL
ML: scikit-learn, optional Sentence Transformers
Parsing: PyMuPDF, python-docx
Tools: VS Code, Git, Postman
